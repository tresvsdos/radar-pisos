# Radar de pisos Zaragoza

Página para revisar los pisos de alquiler que la búsqueda diaria encuentra en
Zaragoza. Se pasa uno a uno: derecha si gusta, izquierda si no.

- `index.html` — la página. No cambia de un día a otro.
- `datos.json` — los pisos del día. Es lo único que reescribe la tarea diaria.

Publicada con GitHub Pages en https://tresvsdos.github.io/radar-pisos/

Las decisiones se guardan en el navegador de quien la abre y se envían por
correo con el botón de abajo; no se guarda ningún dato personal en este
repositorio.
